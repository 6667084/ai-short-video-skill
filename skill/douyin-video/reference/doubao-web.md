# 豆包网页端（会员额度）评估 · 2026-10-03

- **模型**：网页“视频生成”页只能选 Seedance 2.0 / 2.0 Fast / 2.0 Mini；Seedance 2.5 只能在对话/工作任务里由豆包 Agent 调用（会先改写参数并要求“确认”）。
- **产出**：720×1280、HEVC 约 0.73 Mbps（30 秒 3.2MB）、无水印；只能上传参考图，不能上传参考视频。
- **额度**：标准套餐 1 条 30 秒 Seedance 2.5 即用完，约一周后恢复。
- **质量**：与 API 同模型同分辨率效果相当——大字标签正确、斜排小字同样乱码、饮水机水桶同样正放。不是“官方比 API 好”。
- **自动化**：ego-browser（已登录）可读取对话、下载视频（已验证）；但用户协议 5.1.1 禁止未授权第三方工具、付费协议禁止机器人软件，有封号风险。仅建议“半自动”：Agent 准备提示词与参考图并填好表单，由用户本人点击生成，生成后 Agent 下载并接入 video_compose。
- **官方 API**：火山方舟 Seedance 2.5 720p ≈ 1.51 元/秒，与 reAPI eco 720p（30 秒 $6）相当，无明显省钱空间。
