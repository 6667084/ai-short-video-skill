# 踩坑记录（症状 → 原因 → 处理）

## 费用

- **未经确认跑了高价方案** → 违反铁律。处理：所有付费走 quote → 用户确认 → submit；默认执行用户提出的方案。
- **报价与实扣不符** → reapi 的 llms.txt 价格偏低。处理：价格取模型页（catalog.py 已如此）；以 `task_status` 的 usd 为准。
- **草稿升 1080p 反而更贵** → 带白模时升级会重复计参考秒数。处理：见 models-and-pricing.md「草稿模式」。

## 生成质量

- **画面里出现乱码字幕** → 模型渲染中文不可靠。处理：prompt 禁止画面文字，字幕后期加。
- **产品标签小字乱码（16.8L→188L、饮用纯净水→假字）** → 主因是 480p 草稿再经 AI 超分臆造字形；其次参考素材过多（4 图+白模视频）稀释了产品图。豆包官方端同模型 720p 只给 1 张产品图，大字正确但斜排小字同样错。处理：标签特写至少原生 720p，不用 AI 超分；参考少而精；见 prompting.md「产品标签与摆放」。
- **桶装水在饮水机上正放（应瓶口朝下倒扣）** → 场景参考图本身画成了正放，模型照抄参考图（豆包官方端也犯同样错误）。处理：先做摆放正确的参考图并核对；仍错则该镜头用首帧模式。
- **没有 BGM / BGM 盖住人声** → 模型自带音乐不可控。处理：prompt 写“不要背景音乐”，Suno 单独生成后用 `video_compose` 闪避混音。
- **BGM 太小听不见** → 旧版 BGM 未统一响度且重闪避（ratio 6），比人声低 20dB 以上。处理（2026-10-03 已改）：人声/音乐各自 -16 LUFS，bgm_volume 0.35–0.45，轻闪避，实测低 8–9dB。
- **出现双胞胎/分身** → 参考图用了三视图拼图。处理：改单人正面半身照，并在约束中禁止分身。
- **数量不对（如多于 10 桶）** → 模型弱项。处理：写清单层/排列/总数；审片重点看；必要时局部修改（`extra={"omni_reference_task_type":"edit"}`，duration 自动 -1）。

## 素材与网络

- **云超分报“无法读取源视频 / video unavailable”** → 海外节点拉取北京 COS 不稳定。处理：reAPI 产物自动用其 CDN 链接；长期可用香港地域桶或全球加速。失败不扣费。
- **Hermes 调用超时** → Hermes 默认工具超时 120s。处理：所有长任务异步（local_job_status / task_status 的 wait_s ≤110）。

## 字幕与排版

- **字幕挡脸** → 固定位置字幕。处理：`video_compose` 默认人脸感知排版；推镜头特写可能只剩发顶区域，属正常。
- **文字与底框不对齐** → 旧版用位图拼接。处理：已改为 Remotion（浏览器排版）。
- **whisper 在静音处“幻听”出文字（如“字幕志愿者”）** → whisper 已知问题。处理：subtitles_align 只采用与脚本匹配的字，超出视频时长的识别结果丢弃。
- **标题被抖音搜索栏挡住** → 顶部 UI 区估计过小。处理：禁区已按社区实测调为顶部 10%/底部 20%/右侧按钮栏，并由 qa_check 校验。

## 工具层

- **Agent 只看到 “Error executing tool xxx”** → MCP 2.x 隐藏普通异常文本。处理：`ms/mcp_util.make_tool()` 统一转为 ToolError（已修复，新增工具务必用 `tool = make_tool(mcp)` 的 `@tool(...)` 注册）。
- **同一任务花费被重复统计** → 多次查询已完成任务。处理：spend_summary 按 task_id 去重（已修复）。
- **纯生图任务也加载 27 个视频工具的说明（约 17k 字）** → 能力都在一个服务。处理：2026-10-04 按能力拆成 6 个服务（servers/：cos-storage、media-image、media-reapi、media-edit、media-speech、almanac），共用 ms/ 与配置，每个都可单独用于非视频任务。
- **项目产物散落在 ~/Movies/AI-Studio/<job>** → 用户找不到。处理：job 填项目名即写入 ~/Desktop/Self-media/<项目>/产出/；`_` 开头的 job 仍在 ~/Movies/AI-Studio（测试/临时）。

## 产品标签

- **景田水桶标签乱码，而抖音 AI 创作只传一张水桶照片却不乱码** → 我们用参考图模式（4 图 + 白模视频）让模型重画产品，再 480p→AI 超分；抖音那边是图生视频，首帧即真实像素。处理：产品镜头用 image_generate 空场景 + image_composite 贴真实产品图 → video_quote(first_frame)，缓慢运镜；结尾用真实产品图做图片花字定版。
- **首帧模式仍乱码（2026-10-04 算账省钱篇 v2）** → Seedance 2.0 Mini eco 720p 首帧模式，第 0 帧标签小字（净含量 16.8L、饮用纯净水）就已被重画。处理：清楚可读的产品画面一律本地真实像素（image_composite + still_to_video），覆盖到主视频画面、保留音轨；AI 镜头里的产品看不清字即可。
- **改成真实像素后画面变单薄** → 只剩单人对镜口播 + 影棚静态产品，没有生活场景，不如宝妈家庭篇有吸引力。处理：主片仍用旗舰模型做多镜头生活场景（产品远景、侧面、虚焦），产品特写用同风格的生活空场景合成后插入，不要突兀切到影棚。

## 选型

- **真人口播用 Mini，人物假、糊（2026-10-04）** → 极低价档的人脸质感不足以撑起投放主片。处理：`video_options(use_case="ad_people")` 只推荐 Seedance 2.5；Mini 只用于空镜、草稿和已验证的固定 IP。
- **拆段生成后，产品段改用 TTS 补口播，声音前后不一** → Mini 单段最长 15s。处理：主片用 Seedance 2.5 一次生成 ≤30s 的完整口播，产品特写只覆盖画面。
- **不给产品参考图，模型自己编了杂牌水桶并堆成多层（生活场景篇）** → 只要画面里有“水桶”，模型就会画。处理：分镜阶段让 AI 主片完全不出现产品（团长篇），产品画面全部 motion_clip / still_to_video 真实像素。
- **用裁切、模糊色块、平铺 PNG 补救乱码，画面变廉价** → 事后补救的代价大于事前设计。处理：见 SKILL.md「产品零出镜分镜」。
- **两个 Remotion 渲染同时启动，报 “Visited localhost:3001 but got no response”** → 本地页面服务互抢。处理：ms/jobs.render_locked 排队（已修复）。


## 2026-10-05 即梦 CLI 接入

- **即梦 CLI 报 `resource store failed: ret=10002 login fail`** → 走了代理。即梦是国内服务，调用必须直连；`ms/jimeng.py` 已自动去掉代理环境变量。
- **报 `AigcComplianceConfirmationRequired`** → 该模型在此账号首次使用，需用户先在即梦网页端用该模型生成一次。
- **CLI 返回的 estimated_remaining_seconds 约 3500 秒，实际 4.5 分钟完成** → 不要把这个预估转述给用户。
- **即梦视频按 60fps 封装、实际约 24fps** → 逐帧超分会复制帧导致时长被拉长、音画不同步；`tools/upscale.sh` 已改为 `-fps_mode passthrough` 拆帧。
- **seedvr2 放大到 1080p（batch 33）占满 64GB 内存 + 34GB 交换** → 卡死不前。交付标准 720p 时用 Lanczos 即可。
- **登录即梦画布 CLI 后，旧 dreamina CLI 的 user_credit 返回 user_id=0**（时间吻合，因果未证实）→ 生成已切到画布 CLI，旧 CLI 只用于查余额；doctor 会提示重新 `dreamina login`。
- **片头标题美术字遮挡人物**（用户反馈）→ 系列视频可只把标题做成抖音封面，片内不叠。
- **大特写时字幕被避让算法推到额头/头发上** → 字幕候选限定下半屏（0.46–0.78），宁可压下巴；特写里的价格花字用 fixed y 放胸前。
- **480p 放大到 720p，特写细节不如原生 720p**（2026-10-05 同主题对比，用户也觉得 480p 不友好）→ 投放主片建议原生 720p，由用户确认。

## 2026-10-08 十条系列量产

- **片头标题美术字盖住人物**（用户反馈）→ 系列视频标题只做封面（`scripts/make_cover.py`），`video_compose` 不传 `cover_image`。
- **片内 “AI生成” 角标多余** → 抖音/视频号发布时平台会标注；`douyin-ad` 模板已去掉角标。「情景演绎」同理在发布时标注。
- **产品合成进 GPT 假场景很出戏**（比例、光影、接地都不对）→ 改用「产品揭幕」：人物展示手势 + 透明产品动画叠加。
- **人物参考图是中性证件照，视频里人物没情绪** → 参考图按角色主情绪生成（惊喜、兴奋、得意）。
- **算账板只放了 1 桶，口播说 10 桶** → 数量必须与口播一致：10 个产品图层两排落下。
- **棕色字幕在暗场景看不清** → 白字 + 本条主色深描边。
- **手写体在算账板上太细** → 换快乐体或加大到 ≥90px；有条纹的背景给文字加半透明底条。
- **花字压住划线价** → 先排好纵向位置再加花字。
- **“透明背景”贴纸其实带白底/棋盘格** → `image_generate` 在要求透明却得到不透明图时返回 `warning`；必须重生成，不要抠白。
- **固定位置花字（`fixed`）导致 qa_check 报 `KeyError 'box'`** → 已修复（固定卡片补位置框）。
- **模型吞掉最后一句行动号召** → 提示词写“最后一句台词必须完整说完”，结尾镜头 ≥3 秒；漏了用号召花字 + 片尾补。
- **模型多画了一个卡通书包** → 揭幕光效（爆炸星）放在那个位置顺带盖住。
- **生图接口 SOCKS/DNS 报错** → 稍等后并发降到 3 重试。
- **Remotion 报 “Visited localhost but got no response”** → 渲染失败自动以 `--concurrency=4` 重试（已内置）。
- **旧成片用裁切 + 模糊色块遮乱码，画面粗糙**（生活场景篇）→ 找回原始主片（reAPI `task_status` 免费重下），产品镜头换成算账板/产品展示，结尾 6 秒最短补拍（120 积分）+ 揭幕，口播保留原声。见 storyboard-product-zero.md「重剪已有成片」。
- **改了成片文件名，封面标题还是旧名** → 封面标题引用片名时一起重做。
