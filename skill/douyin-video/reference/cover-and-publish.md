# 封面与发布

## 封面

**标题美术字只放封面，不叠进视频**——片头 2.5 秒的大标题会盖住人物的脸和动作（用户反馈后全系列去掉）。

步骤：
1. `image_generate(size="1536x1024", background="transparent")` 生成本条标题美术字：≤2 行、每行 ≤8 字，第一行钩子、第二行利益点；风格与本条一致。逐字核对、确认真透明。
   ```
   真正透明背景（alpha 透明，不要画棋盘格）的抖音短视频标题美术字，只包含两行文字，不要任何其他文字：第一行「老公你买贵了！」，第二行「10桶才99」。
   超粗圆润黑体，3D 立体效果。第一行白色字配厚实的深蓝色描边和蓝色立体厚度，“贵”字略放大并微微倾斜，表现夸张吃惊。
   第二行“10桶才”是白色字放在蓝色圆角底座上，“99”是超大号亮黄色立体数字。周围点缀晶莹的水花、水珠和闪光。高饱和、边缘清晰锐利。
   ```
2. 选帧：AI 主片里**表情最夸张、脸最大**的一帧（惊讶瞪眼、大笑、举杯），通常在前 3 秒或高潮处。用主片而不是成片（成片带字幕）。
3. 合成：`python scripts/make_cover.py --video <主片> --t 1.6 --title <标题.png> --out <产出/final/…_抖音封面.png>`
   - 输出 1080×1920；标题宽 720–900px，底边默认在 y=1680（**3:4 裁切安全区 y 240–1680 的下部**），压在下巴/衣领/桌面上，**不挡眼睛和嘴**。
   - 720p 素材自动 Lanczos 放大 + 轻锐化。
4. 看图：缩略图下看标题是否清楚、脸是否完整；抖音个人页按 3:4 裁切显示，标题不能出安全区。

封面墙示例：`docs/images/06_cover_wall.jpg`。

## 发布文案（视频介绍）

模板：[../templates/发布文案模板.md](../templates/发布文案模板.md)

```
**视频介绍**：泡茶几十年的老茶友，烧水只认大品牌🍵 景田16.8升10桶99，茶友们按需囤👇 #景田纯净水 #喝茶 #泡茶 #山西 #茶生活
```

- 1–2 句：人群/场景 + 利益点 + 行动号召（👇 指向团购链接）；1–3 个 emoji。
- 话题 4–6 个：品牌词、品类词、人群/场景词、地域词（本地团购必加城市/省份）、生活方式词。
- 不写极限词与功效词；价格与成片一致。

## 发布时（在平台上做，不压进画面）

- 勾选「内容由 AI 生成」（抖音、视频号都有）。
- 情景剧标注「情景演绎」。
- 挂团购/商品链接；行动号召与实际转化方式一致。
- 上传自定义封面；视频号另选 3:4 / 1:1 封面裁切时确认标题仍完整。

## 文件命名

`产出/final/<品牌>_<篇名>.mp4` 与 `<品牌>_<篇名>_抖音封面.png` 成对；改名时封面标题如引用了旧名也要重做（例：「老公买贵了 v2」改名「老公你买贵了」后重做了封面标题）。
