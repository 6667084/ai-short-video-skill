# 每条单独设计的视觉风格

## 字体（compose/public/fonts，均为 SIL OFL，可商用）

| 别名 | 字体 | 用途 |
|---|---|---|
| 黑体（默认） | 思源黑体 Heavy / Bold | 最稳，任何风格 |
| 快乐体 | 站酷快乐体 | 可爱、生活、综艺 |
| 黄油体 | 站酷庆科黄油体 | 冲击力、综艺、喜庆 |
| 毛笔 | 马善政毛笔楷书 | 新中式 |
| 手写 | 龙藏体 | 温情、手账（笔画细，字号 ≥90） |
| 宋体 | 站酷小薇 | 极简、文艺 |

`video_compose(caption_font=…, caption_color=…, caption_highlight=…, caption_stroke=…)` 改字幕；花字卡与 motion_clip 文字层用 `font` 字段。

## 配色与可读性

- 字幕统一**白字 + 本条主色深描边**最稳；深色/棕色字在暗场景看不清（实测返工过）。
- 高亮色（数字、【关键词】）用亮黄 `#FFE14D` 或本条强调色。
- 算账板文字放在半透明底条上；背景有条纹/纹理时必须加。

## 贴纸提示词：风格句

每条写一个风格句 `STK`，所有贴纸都用 `STK + "文字只有「…」"`，保证同条统一、跨条不同：

- 手账：`真正透明背景（alpha 透明，不要画棋盘格）的手账风贴纸，只包含指定文字……奶油色纸胶带底，马克笔手写感粗字，深棕描边，旁边有手绘小星星、小爱心和箭头涂鸦。`
- 综艺：`……抖音综艺爆炸贴纸……漫画爆炸星形底（锯齿边缘的亮黄色爆炸星，外圈番茄红描边），超粗圆润黄油体字，白色字配厚红色描边和深红立体投影，周围有黑色速度线和小闪光。`
- 新中式：`……新中式国潮贴纸……米白宣纸底，毛笔书法字，墨黑字配朱红印章，水墨晕染边缘。`
- 晨光：`……晨光生活风贴纸……暖橙到蜜桃色渐变的圆角胶囊底，外圈白色粗描边，超粗圆润字体，白色字配深橙色描边和柔和投影，旁边点缀一轮小太阳、晶莹水滴和白色闪光。`
