## 模板（video_compose 的 template）

| 模板 | 内容 |
|---|---|
| `douyin-ad` | 剪映爆款风字幕（白字粗描边、数字与【关键词】黄色高亮、自动避让人脸）；花字默认黄字黑描边；BGM 0.4；1080p。**不加 “AI生成” 角标**（平台发布时标注）；`cover_image` 可选，系列视频通常不传（标题只做封面） |

可在 `templates/<名>.json` 自建品牌版式（固定角标、机构条、字幕位置）。

## 字幕行（subtitles_align 的 lines）

- 按口播顺序，每行 ≤12 字，一行一个信息点，断在自然停顿处。
- 显示与读法不同时写 `"显示|读法"`：`"10桶要160元|十桶要一百六"`、`"平均每桶9.9元|平均一桶九块九"`。
- 句尾保留 `！？`，去掉 `，。`。
- 关键词高亮：显示部分用【】包住，如 `"景田【大品牌】放心喝|景田大品牌放心喝"`（数字价格自动高亮）。每句最多 1 处。
- `matched_lines` 必须全中；未中先 `transcribe` 看是否念错，再决定改字幕、补花字还是补拍。
- 对齐结果存成 `文案/<篇名>/字幕对齐.json`，后续插入时间、花字时间都从这里取。

## 字幕样式（每条单独）

`video_compose(caption_font="快乐体", caption_color="#FFFFFF", caption_highlight="#FFE14D", caption_stroke="#9C3D0B")`

- 白字 + 本条主色深描边最稳；不要用深色字（暗场景看不清）。
- 字体别名：黑体 / 快乐体 / 黄油体 / 毛笔 / 手写 / 宋体（见 visual-styles.md）。

## 花字 / 价格卡（video_compose 的 cards）

| 用途 | 写法 |
|---|---|
| 图片花字 | `{"image": "<透明底PNG>", "start": .., "end": .., "size": 820}`（size=宽度 px） |
| 钩子文字 | `{"text": "家里喝水多的 先别划走！", "start": .15, "end": 2.86, "size": 84, "color": "#FFF", "stroke": "#9C3D0B", "bg": "#E8711E", "font": "快乐体"}` |
| 划线原价 | `{"text": "原价16元/桶", "size": 96, "color": "#FFF", "bg": "rgba(0,0,0,0.62)", "strike": true}` |
| 固定位置（大特写） | 加 `"fixed": true, "y": 0.6`（胸前）或 `0.2`（头顶上方），不让避让算法乱推 |

- 时间对准 `subtitles_align` 的对应句。价格类主要由算账板动画承担，cards 只做补充，不要和算账板重复出现。
- 结尾号召被模型漏说时，用号召花字补在最后一个人物镜头上。

## 自动排版规则（video_compose 内置）

- **抖音 UI 禁区**（硬约束）：顶部 10%（192px）、底部 20%（384px）、右侧 15% 在 40–85% 高度（按钮栏）。数值为社区实测稳妥值，平台无官方像素规范；视频号与此接近。
- **字幕只在下半屏**：候选高度 0.46–0.78，用 Apple Vision 逐句检测人脸，选“不压五官、不进禁区、离默认最近”的位置，带粘滞避免跳动。大特写时宁可压下巴/衣领，不上额头。
- 压五官全权重；压头发/脖子 0.3 权重。
- 花字在 12%–72% 高度内同样避让，放不下时自动缩小；字幕会避开同时出现的花字。
- 字号：正文 65–95px（默认 72），标题 130–170px。

审片图：`docs/images/07_qa_safe_zone.jpg`（红色为禁区）。

## QA 阈值（qa_check）

| 项 | 标准 | 级别 |
|---|---|---|
| 规格 | 1080×1920、30fps、有音轨、时长与工程一致 | fail |
| 响度 | -14±1.5 LUFS | fail |
| 真峰值 | ≤ -1 dBTP | warn |
| 字幕停留 | 每条 ≥0.6s | warn |
| 阅读速度 | ≤9 字/秒 | warn |
| 挡脸 | 压五官最差帧 ≤0.10 | warn |
| UI 禁区 | 0 处 | fail |
| 黑场 / ≥1.5s 静音 | 无 | warn |

`review_image` 必须看图复核；常见可接受的 warn：大特写时字幕落在下巴附近（不挡眼睛和嘴）。
